# Standalone SoccerMaster scale experiment

This package is the soccer-only scaled research path. It owns its data manifest, taxonomy, frame sampling, frozen-feature baseline, local VLM evaluation, evidence reports, and verification. It imports neither `footballmaster` nor the multi-sport demo server.

## Data boundary

- Source: user-authorized SoccerNet NDA access.
- Use: local, non-commercial research only.
- Redistribution: not allowed.
- Raw match media, frame features, contact sheets, raw VLM responses, and sealed labels stay under `data/private/soccermaster-scale-v1`.
- Public-safe aggregate receipts and trained-probe artifacts live under `artifacts/soccermaster-scale-v1`.
- The SoccerNet password is OCR'd in memory by the pre-existing authorized downloader and is never printed or persisted.

## Frozen experiment

- Corpus: eight complete matches / 16 halves / 12.4222 decoded hours.
- Split unit: whole SoccerNet game, with four train, two validation, and two test games.
- Taxonomy: 14 candidate classes—background plus 13 event categories. SoccerNet's 17 source labels are collapsed only where the visual distinction is especially underdetermined at this pilot scale (shot on/off target, direct/indirect free kick, and card color).
- Candidate window: 12 seconds. Visible SoccerNet-v2 annotations select positive centers; deterministic background windows are at least 12 seconds from every visible event.
- Ambiguity filter: evaluation/training uses windows without a different mapped class inside four seconds of the center.

## Two deliberately separate model paths

1. **Non-VLM baseline.** Twelve silent frames are passed through a frozen ImageNet MobileNetV2 ONNX model. Mean, standard deviation, max, end-to-start, and center-to-edge aggregates produce a 5,000-dimensional descriptor. A fixed random projection and a class-balanced multinomial head are fit on train games; five candidates are selected on validation games; test games remain frozen.
2. **Primary local VLM probe.** Fifty test windows are frozen before inference. The inference manifest contains no labels; a separate sealed-label file is opened only by the scorer. `google/gemma-4-e4b` receives eight silent frames as two contact sheets, a fixed taxonomy prompt, and a strict JSON schema. Every request, raw response, prediction, latency, model identity, and failure is persisted.

Neither path is dense full-match spotting. Candidate discovery, player identity, team identity, long-ball recognition, formations, tactical intent, trajectory, and coaching impact remain unevaluated.

### Frozen results

- Non-VLM baseline: 389 held-out candidates, 42.93% exact accuracy versus a 23.91% train-majority baseline; top-3 accuracy 75.58%.
- Gemma-4-E4B: 50/50 schema-valid responses, 24 abstentions, 3/50 exact correct (6.0%) versus an 8.0% majority baseline on the stratified subset.
- Interpretation: the data/evaluation pipeline works, but the tested zero-shot VLM is a semantic **NO-GO**. Detailed VLM prose is not factuality-scored and is unsafe for coach search.

## Reproduce

Run commands from the repository root with the checked local SoccerNet environment:

```powershell
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale build-manifest
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale verify-manifest
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale fetch-backbone
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale extract-features
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale train --epochs 350
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale verify-package
```

The VLM subset is immutable once frozen. Do not rerun `freeze-vlm-subset` over an existing directory:

```powershell
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale freeze-vlm-subset
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale run-vlm
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale score-vlm
.\.venv-soccernet\Scripts\python.exe -m prototype.soccermaster_scale verify-vlm
```

`run-vlm` resumes only hash-consistent completed examples. Any drift fails closed.

## Interpretation contract

- The candidate class probability is learned by the non-VLM baseline or generated by the explicitly named VLM.
- Candidate/window timestamps are deterministic metadata, not learned localization.
- The prose report is a deterministic template or raw VLM field, not an independently verified coaching claim.
- Unsupported player, location, trajectory, and tactic fields remain null or `unavailable`.
- All results are feasibility diagnostics. Public artifacts set `performance_claim_allowed` to false.
