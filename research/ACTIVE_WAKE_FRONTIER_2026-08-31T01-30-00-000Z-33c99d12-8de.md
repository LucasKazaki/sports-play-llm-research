# Active Wake Public‑Source Frontier

## Objective
Create a provider‑neutral, rights‑failing benchmark or evaluation improvement that defines observed‑versus‑proposed labels, three measurable acceptance criteria, one exact implementation handoff, and one stop condition.

## Benchmark Definition
- **Observed label**: Current model output on a public‑source soccer event card (e.g., “Goal by Player X at minute 23”).
- **Proposed label**: Refined, context‑aware event description generated by the new benchmark pipeline.

## Acceptance Criteria
1. **Label Accuracy** – Proposed labels must match observed labels in ≥ 90 % of test cases.
2. **Runtime Overhead** – Benchmark runtime ≤ 1.5× baseline inference time.
3. **Data Provenance** – All data used must be openly licensed; no private or NDA content is referenced.

## Implementation Handoff
- Provide a Python module `benchmark.py` with a function `run_benchmark()` that accepts a list of event card strings and returns proposed labels.
- Include unit tests in `tests/test_benchmark.py` verifying the three acceptance criteria.

## Stop Condition
If any test fails or if non‑public data is detected, halt further development and report the failure.
