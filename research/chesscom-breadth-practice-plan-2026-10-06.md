## Next bounded experiment

1. Build a versioned no-forward practice packet for each selected move. It may contain only the source-bound pre-move board, the selected legal move, deterministic transition facts, one typed, qualified engine observation for *that move* if obtained through the registered project executor, and source/engine identity. Audit the exact field allowlist and hashes before any generator call. **Never pass** the PGN annotation or side variation, the rest of the mainline, future board states, opponent replies, engine PVs, alternative scores, evaluator witnesses, or review labels to the generator.
2. First test that the generalized output schema can represent these four mechanisms or abstain. Use legal replay and negative-control software tests before freezing any requests. The current queen-defense-specific checker is not evidence that it can explain queen escape, check, rook coordination, or pawn defense.
3. If the route and source review pass, freeze **one create-only local model attempt per case: four planned attempts, counted as four whether valid, malformed, empty, timed out, or interrupted**. Save each request hash, raw response, model identity, latency, and failure. After generation, a separate evaluator may replay the model's *named* line and, if needed, run bounded paired engine searches through the registered native executor. Do not feed those findings back into the same attempt.
4. Report legality and board-fact accuracy for every checkable assertion, typed engine-reference validity, support for each strategic hypothesis, abstention, format failures, latency, and a per-case teaching judgment separately. Record both the numerator and denominator for each. A qualified chess reviewer or explicitly limited rubric is needed for teaching value. Failures should drive one bounded repair and a newly versioned attempt; they do not erase the original four-case denominator.

This practice cannot support Chess.com parity, “all Stockfish moves,” or expansion to other games. The [no-forward commentary gate](chess-commentary-capability-gate-v1.md) still requires a separately frozen, stratified, game-disjoint holdout and independent review before a capability claim.
