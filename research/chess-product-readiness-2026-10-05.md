# Chess local product readiness — 2026-10-05

**Decision:** a useful offline chess evidence review is available for local
use. A professional commentary product is **not** accepted. This note is an
internal engineering receipt, not a shareable research promotion.

## What can be used now

| Path | User action | Actual behavior |
| --- | --- | --- |
| `artifacts/chess-evidence-review-v1/index.html` | Open the saved page and select one of eight cases | Shows real CC0 Lichess development positions, source links, before/after boards, 16 legally replayed searched moves, rule facts, typed saved engine scores, raw engine lines kept separate, and honest model-result status. |
| `scripts/chess_review_completed_game.py` | Supply one completed standard-chess PGN and a ply | Produces a create-only local HTML review, JSON evidence receipt, and annotated PGN. It replays the game legally, analyzes the played move and another move in separate bounded Stockfish searches, and makes no model or network call. |
| `artifacts/chess-completed-game-review-v2/synthetic-demo/index.html` | Open the saved software demonstration | Shows a legally finished four-ply synthetic checkmate game. It is a demo, not a real-data metric. |

The [usage guide](../prototype/CHESS_EVIDENCE_REVIEW.md) has exact run and
verification commands. The local engine is Stockfish 19 with binary SHA-256
`45bc8e4969147db9c2eb533810637994619bff0eacc81ccfd9854394901bcbd0`.
The PGN tool requests 10,000 nodes per search by default (1,000–100,000
allowed), retains observed nodes, perspective, score type and bound, and
identifies the played move's root-restricted search. Its saved demonstration
observed a mate score on the played move and a separate centipawn observation
for another move; the page makes no numerical superiority claim.
