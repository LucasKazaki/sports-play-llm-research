# Active Wake Public‑Source Frontier

**Objective**: Define a provider‑neutral, rights‑failing benchmark or evaluation improvement for Sports Play LLM research.

## Benchmark Concept

* **Observed labels** – Current public‑source annotations from SoccerNet‑Open (e.g., event type, player ID).
* **Proposed labels** – Model‑generated event cards produced by the new SportsPlayLLM checkpoint.

The benchmark will compare *observed* vs. *proposed* labels on a held‑out set of 10 publicly licensed clips, ensuring no private data is used.

## Acceptance Criteria (measurable)
1. **Precision** ≥ 0.80 for event type classification.
2. **Recall** ≥ 0.75 for player identification.
3. **F1‑score** ≥ 0.77 across both tasks.

All metrics are computed on the public clip set only; any deviation triggers a stop condition.

## Implementation Handoff
* Create a Python script `scripts/eval_public.py` that:
  * Loads the public clip metadata.
  * Runs the SportsPlayLLM checkpoint to generate event cards.
  * Computes the three metrics against SoccerNet‑Open annotations.
  * Outputs a JSON report.

The script will be placed under `src/benchmarks/public_eval/eval_public.py` and documented in the repo README.

## Stop Condition
If any metric falls below its threshold, halt further benchmarking and flag the issue for review.
