# Active Wake Public‑Source Frontier

## Objective
Create a provider‑neutral, rights‑failing benchmark or evaluation improvement for Sports Play LLM research. The memo defines observed‑versus‑proposed labels, three measurable acceptance criteria, an exact implementation handoff, and a stop condition.

## Benchmark Definition
- **Observed label**: Current model performance on publicly available soccer event detection (e.g., goal, off‑side) measured via precision/recall on a held‑out public dataset.
- **Proposed label**: Target performance after applying the new evaluation improvement (e.g., incorporating a contrastive loss or data augmentation).

## Acceptance Criteria
1. **Precision increase ≥ 5 %** over observed baseline.
2. **Recall increase ≥ 3 %** over observed baseline.
3. **F1‑score increase ≥ 4 %** over observed baseline.

All criteria must be met on a public, openly licensed validation set.

## Implementation Handoff
- Deliver a Python script `scripts/benchmark_improvement.py` that:
  1. Loads the public dataset via `datasets.load_dataset("soccer_events_public")`.
  2. Applies the proposed improvement (e.g., data augmentation pipeline).
  3. Trains the model for one epoch and evaluates precision, recall, F1.
  4. Outputs results to `results/benchmark_improvement.json`.

The script must be runnable with `python scripts/benchmark_improvement.py` in a conda environment containing `transformers`, `datasets`, and `torch`.

## Stop Condition
If any of the acceptance criteria are not met after three training runs, halt further experimentation and report the shortfall.
